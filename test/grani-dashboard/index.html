データの連携状況

今はCSV取込で動きます。API連携（自動取得）は本番版で追加予定です。

CSVを取り込む

チャネルの枠にCSVをドロップするか、クリックして選びます。列は自動で読み取ります。ずれていたら各ファイルの「列の割り当て」で直せます。同じチャネル・同じ日付のデータは新しいファイルで上書きされます。

CSVの出し方（目安）
  • 公式サイト（GA4）：レポート → 集客 → トラフィック獲得 など → 右上の共有 → ファイルをダウンロード → CSV。セカンダリディメンションに「日付」を入れると日別になります。
  • 楽天：RMS → データ分析 → アクセス・流入分析 / 店舗カルテ などで日別に表示 → CSVダウンロード。
  • Amazon：セラーセントラル → レポート → ビジネスレポート → 「日付別」の売上・トラフィック → CSVでダウンロード。
  • Qoo10：QSM → 統計 / 販売分析 の日別データ → Excel/CSVダウンロード（Excelの場合はCSVで保存し直してください）。
  • どのCSVも「日付」「訪問数（セッション・アクセス人数）」「注文数」「売上」の列があれば読み込めます。メニュー名は時期により変わることがあります。

データはこのブラウザの中だけに保存され、外部には送信されません。別のPCや他の人には共有されないので、共有したいときは「まとめたデータをコピー」で書き出してください。
