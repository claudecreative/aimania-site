ECOLEAD WEBSITE RENEWAL / 2026.11

親しみやすさを、
安心して相談できる体験へ。

エコリード様 Webサイトリニューアルのご提案

参考サイトの明るさ・わかりやすさを踏襲し、
信頼感・安心感・使いやすさを高めます。

1. 参考サイトから受け継ぐもの

緑とオレンジのはっきりした配色、大きな訴求文字、親しみのある人物イラスト、写真との組み合わせ、複数の相談窓口。この「気軽に頼めそう」という印象を、リニューアルの核とします。

参考：https://ecobee.jp/ ／ 現行：https://ecolead.jp/（2026年11月14日確認）。問い合わせ増加などの実績値は未検証のため、以下は設計上の狙いです。

2. 何を、なぜ改善するのか

項目改善内容お客様にとってのメリット
画面の幅現行の本文上限1,100pxを、最大1,360pxへ。メイン画面は最大1,440px。写真・文字を大きく見せ、内容をひと目で把握しやすくする。
配色緑を基本に、オレンジは重要な訴求、黄色は強調に用途を整理。にぎやかさを保ちながら、見るべき場所をわかりやすくする。
文字見出し・説明・注記の大きさを分け、文字をHTMLで組む。スマホでも読める。文章の修正や拡大にも対応しやすい。
イラスト・写真親しみのある人物を残し、線と色を統一。生活感のある写真を併用。相談のハードルを下げ、片付いた暮らしを具体的に想像できる。
相談の入口PCはヘッダー固定、スマホは電話・LINEを画面下に固定。ページのどこにいても、相談先を探す必要がない。
料金・安心情報無料の範囲と作業費用の違いを明示。査定後に判断できる流れを掲載。「あとで費用がかかる？」という不安を減らす。
動きイラストと吹き出しの小さな動き、品目の拡大表示、FAQ開閉を実装。親しみと操作のわかりやすさを両立。停止・動きの抑制にも対応。

3. 参考サイトの構成・情報の順番を踏襲

メイン → 紹介 → お悩み → 選ばれる理由 → サービス → 品目 → 買取実績 → 買取の流れ → お客様の声 → FAQ → お問い合わせ → 会社概要。最後に笑顔のイラストと相談導線を加えます。

長い説明を一度に見せず、写真・短い見出し・品目の詳細表示・質問の開閉で段階的に伝えます。相談ボタンは最上部だけでなく、サービスを理解したタイミングにも設置します。

4. 今回のデザインで実装したもの

  • PC・タブレット・スマートフォンに合わせたレイアウト
  • 固定ナビ、電話・LINEへのリンク、現行メール窓口への導線
  • 人物イラストと吹き出しのアニメーション、スクロール表示演出
  • 買取品目20カテゴリーの拡大・詳細表示、買取実績スライダー、4ステップの買取手順、よくある質問の開閉
  • キーボード操作、動きの停止、端末の動き抑制設定への対応

5. 本番公開までに整えるもの

今回はデザインと操作性を確認するための別URLです。現行サイトは変更していません。

  • 実際のスタッフ・作業風景写真、掲載許諾済みの実績・お客様の声
  • 会社情報、所在地、連絡先・営業時間・対応エリア、許認可等の掲載内容
  • 無料対象、回収・作業費、本人確認等の実際の運用に合わせた文言確認
  • 日本語の問い合わせフォーム、送信先、個人情報の取り扱い、受信テスト
  • 本番環境への反映と端末検証、問い合わせ計測の設定

公開後は、電話・LINE・メールのクリック数、実際の問い合わせ完了数、スマホでの離脱箇所を確認し、改善を続けます。

写真はUnsplashのイメージ素材、人物はイラストです。実スタッフ・実案件の実績を示すものではありません。ロゴはご支給の正式データを使用しています。効果の数値保証は行いません。
