# AI mania テストアップ指示書

制作物を AI mania のテストルーム（https://aimania.tech/test/）に上げ、パスワード付きで見られるようにする手順です。

## 前提
- リポジトリ：GitHub の `claudecreative/aimania-site`（GitHub Pages で aimania.tech に公開。main に push すると1〜2分で反映）
- テストページは `test/<slug>/` に置く。追加・更新は必ず `tools/add_test_page.py` を使う（手で test/index.html を書き換えない）

## 手順
1. リポジトリを用意して最新にする
   ```
   git clone https://github.com/claudecreative/aimania-site.git   # 初回のみ
   cd aimania-site && git pull --rebase origin main
   ```
2. 上げたいものを1つのフォルダにまとめる
   - 入口は `index.html`。画像・CSS・JS は相対パス（`img/a.webp` など）で参照し、同じフォルダに入れる
   - 外部への埋め込みはフォント（Google Fonts）程度にとどめる。秘密情報・個人情報・本物の企業ロゴの無断使用は入れない
   - Claude のアーティファクトから持ってくる場合は、全ファイル（index.html と img/ 以下）を取り出してフォルダに保存する
3. スクリプトを実行する
   ```
   python3 tools/add_test_page.py <slug> "<一覧に出す名前>" <フォルダ>
   ```
   - `<slug>`：英小文字・数字・ハイフン（例：`hodoke`、`jutec-movie`）。URL になる
   - パスワードは自動で作られる（例：`hodoke7183`）。指定したいときは `--pw <英小文字と数字>`、共通パスワード（test）で良いときは `--pw shared`
   - 同じ slug でもう一度実行すると上書き更新になる（パスワードも作り直されるので、変えたくないときは `--pw` で前と同じものを指定）
4. 公開する
   ```
   git add -A test && git commit -m "テスト: <名前> を追加" && git pull --rebase origin main && git push origin main
   ```
5. 確認する（push の1〜2分後）
   - `curl -s -o /dev/null -w "%{http_code}" https://aimania.tech/test/<slug>/` が 200
   - 画像も1枚 200 になるか確認（`.../test/<slug>/img/xxx.webp`）
   - できればブラウザで URL を開き、パスワード画面 → 入力 → ページが出ることを確認

## 報告のしかた
次の形で返す。
```
<名前>
URL：https://aimania.tech/test/<slug>/
パスワード：<スクリプトが表示したもの>
```

## 守ること
- パスワードはサイトごとに別。報告以外の場所（コミットメッセージ、ページ本文など）に書かない
- 既存の他のテストページのフォルダは触らない
- push が失敗したら `git pull --rebase origin main` してからやり直す。強制 push はしない
- スクリプトがエラーを出したら、そのまま作業を止めてエラー文を報告する
